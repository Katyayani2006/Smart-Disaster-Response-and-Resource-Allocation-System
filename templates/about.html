About Smart Disaster Emergency Response System

A practical, state-level triage and dynamic resource allocation platform designed to streamline emergency command operations during floods, cyclones, and structural disasters.

1. Public Citizen Emergency SOS Portal (`/sos`)

Allows disaster-affected citizens to lodge emergency distress alerts directly without authentication. Captures location, disaster type, casualty estimates, and specific help requirements. Each distress call generates a unique tracking code (e.g. SOS-A8F3B1) and automatically resolution coordinates for live map visualization.

2. Machine Learning Priority Prediction (`/predict`)

Every incident is evaluated by a trained Random Forest Classifier model based on five key disaster parameters: severity (1–10 scale), affected population, infrastructure damage (1–10), site accessibility (1–10), and historical disaster frequency. The model outputs priority levels — CRITICAL, HIGH, MEDIUM, or LOW — complete with probability confidence scores (predict_proba()) and global feature importance.

3. Dynamic Urgency Scoring & Alias Normalization

Combines predicted priority with casualty count and severity into a single 0–100 urgency score. Crucially, the system includes a Location Alias Engine that normalizes common spelling variants (e.g., Balesore → Baleswar, Kendrapada → Kendrapara) so data inaccuracies don't disrupt spatial algorithms.

4. Spatial Haversine Resource Allocation Engine

When command officers trigger allocation, the engine ranks open incidents by urgency score, then computes exact Great-Circle distance to available response depots using the Haversine Formula:
$$d = 2R \arcsin\left(\sqrt{\sin^2\left(\frac{\Delta \phi}{2}\right) + \cos(\phi_1)\cos(\phi_2)\sin^2\left(\frac{\Delta \lambda}{2}\right)}\right)$$ Resource types (Inflatable Boats, Hydraulic Cutters, MFR Kits, Water Purifiers) are matched from the nearest available depot, preventing double-allocation and reducing transit delays.

5. Government Dispatch Audit Log & PDF Exporter (`/export-report`)

Provides complete transparency for government audits. Generates official printable dispatch receipts summarizing active emergencies, depot inventory readiness, allocated quantities, Haversine transit distances in km, and authorization signature blocks.

6. Multi-Role Security & System Architecture

- Admin / Officer (`admin` / `officer1`): Full control to manage inventory, verify reports, execute allocations, and reset sessions.
- Field Viewer (`viewer1`): Operational readiness monitoring.
- Public Citizen: Unauthenticated SOS distress reporting.
